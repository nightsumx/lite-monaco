    05坦白平替最怕“看起来一样”

    已知的不一样，写在明处。

    • KNOWN-01输入层不同

      Monaco 用隐藏的 textarea / EditContext，lite-monaco 用 contenteditable。读屏的 role 和 aria 属性对齐了，无障碍树的结构没法一样。VoiceOver、NVDA、JAWS 都没测过。

    • KNOWN-02输入法组字过程不同

      Monaco 每次组字更新都改一次 model，lite-monaco 到提交才改。提交后的结果一致。用 CDP 模拟过，没在真机输入法上验证。

    • KNOWN-03不是 VS Code 平台

      没有 editor.createWebWorker、languages.*.getWorker，没有多文件 diff 编辑器，accessibilityPageSize 分页也不做。

    • KNOWN-04浏览器覆盖

      Chromium、Firefox、WebKit 的 Playwright 构建都跑了。真 Safari、真触摸屏的选区手柄和软键盘没有验证。

    • KNOWN-05TypeScript 智能要另装

      补全、hover、诊断、跳转靠可选依赖 typescript。这个页面没带它，所以页面上的 TS 只有高亮和编辑。
